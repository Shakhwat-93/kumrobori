# কুমড়ো বড়ি — ল্যান্ডিং পেজ (React + Vite)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ ফোল্ডারে প্রোডাকশন বিল্ড
```

- দাম/প্যাকেজ বদলাতে: `src/data.js`
- রং (color palette): `src/index.css` এর `:root`
- ছবি: `public/img/`
- অর্ডার ফর্ম এখন শুধু UI — `src/App.jsx` এ `// TODO` লেখা জায়গায় API/Google Sheet যুক্ত করুন।
